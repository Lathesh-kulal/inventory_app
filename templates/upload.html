Expected CSV Format

Download Sample CSV

Your file must contain the following 12 columns. Each row represents one time period (e.g. one month) for a specific product.

  • Date — ISO format YYYY-MM-DD
  • SKU — Unique product ID
  • Category — Product category
  • Sales — Numeric units sold in that period
  • Unit_Price — Base price of the unit
  • Cost_Price — Cost of the unit
  • Selling_Price — Actual price sold at
  • Discount_Pct — Discount percentage (0-100)
  • Is_Promotion — 1 if during promotion, else 0
  • Is_Holiday — 1 if holiday period, else 0
  • Current_Stock — Units currently in stock
  • Lead_Time_Days — Days to restock
